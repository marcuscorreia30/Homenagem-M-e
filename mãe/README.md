# Homenagem a Luciane - Dia das Mães

Uma página web especial criada para homenagear Luciane no Dia das Mães, com design elegante em tons de roxo e branco.

## ✨ Funcionalidades

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e smartphone
- **Animações Interativas**: Botões que criam confetes de flores e corações
- **Galeria de Fotos**: Lightbox para visualizar imagens em tamanho maior
- **Conteúdo Rico**: Histórias, memórias e mensagens especiais
- **Layout Profissional**: Inspiração no estilo de grandes marcas

## 🎨 Características do Design

- Tema em roxo meia-noite com branco
- Gradientes sutis e sombras elegantes
- Tipografia moderna e legível
- Animações suaves de scroll
- Interface intuitiva e acessível

## 🚀 Como Hospedar

Este site está pronto para ser hospedado gratuitamente no GitHub Pages:

1. Crie uma conta no [GitHub](https://github.com)
2. Crie um novo repositório público
3. Faça upload de todos os arquivos desta pasta
4. Vá para Settings > Pages
5. Selecione "main" como branch e "root" como folder
6. O site ficará disponível em: `https://seu-usuario.github.io/nome-do-repositorio`
