# Fotos para o Site de Homenagem

Para personalizar o site com suas próprias fotos, adicione as seguintes imagens nesta pasta:

## Fotos Necessárias:

1. **familia antiga.jpg** - Foto de aniversário de 2012
2. **foto2.jpg** - Foto de Natal de 2015
3. **foto3.jpg** - Foto do Dia das Mães de 2019
4. **foto4.jpg** - Foto da viagem de 2022
5. **foto5.jpg** - Foto da festa em família de 2025
6. **foto6.jpg** - Foto do Dia das Mães de 2026

## Instruções:

- **Formato:** JPG, PNG ou WebP
- **Tamanho recomendado:** 800x800 pixels (quadradas)
- **Qualidade:** Boa resolução para web
- **Nomes dos arquivos:** Devem ser exatamente como especificado acima

## Dicas:

- Use fotos de boa qualidade
- Certifique-se de que as fotos são apropriadas para compartilhamento
- Mantenha o tamanho dos arquivos razoável (menos de 2MB cada)

## Funcionalidades:

- Clique nas fotos para visualizá-las em tamanho maior
- Use ESC ou clique fora da imagem para fechar o lightbox

Após adicionar as fotos, recarregue a página no navegador para ver as mudanças!
